Installer URL entry points

GitHub Pages publishes this branch. Each PowerShell entry point fetches its current upstream installer.

/office/install.ps1 -> Ehsan-U/office2024-installer master/src/Install-Office.ps1
/wrider/install.ps1 -> Ehsan-U/wrider-downloads main/install.ps1
/install.ps1 and / retain the original WRider entry point.

No installers or plugin binaries are embedded here.
